FORME — Minimal 3D Store
========================

เว็บไซต์ตัวอย่างร้านเสื้อผ้าและรองเท้า จำนวน 3 หน้า
1) index.html  = หน้าแรก / แนะนำร้าน / สินค้าแนะนำ
2) shop.html   = หน้ารวมสินค้า / ตัวกรอง / ดูสินค้าแบบ 3D / เพิ่มลงตะกร้า
3) cart.html   = ตะกร้าสินค้า / แก้จำนวน / ลบสินค้า / ฟอร์มสั่งซื้อทดลอง

วิธีเปิดใช้งาน (แนะนำ)
1. แตกไฟล์ ZIP
2. เปิดโฟลเดอร์ forme_3d_store ด้วย VS Code
3. ติดตั้งส่วนขยาย Live Server
4. คลิกขวา index.html แล้วเลือก Open with Live Server
5. ใช้งานเมนู หน้าแรก / สินค้า / ตะกร้า ได้เลย

หมายเหตุ
- ต้องเชื่อมต่ออินเทอร์เน็ตเพื่อโหลด Three.js จาก CDN, Google Fonts และภาพตัวอย่าง
- โมเดลรองเท้า 3D สร้างจากรูปทรงเรขาคณิตด้วย Three.js ภายในไฟล์ three-scene.js
  สามารถลากเมาส์เพื่อหมุน และใช้ล้อเมาส์เพื่อซูมได้
- ตะกร้าสินค้าเก็บใน localStorage ของเบราว์เซอร์
- การสั่งซื้อเป็นระบบสาธิต ยังไม่เชื่อมต่อ Payment Gateway, ฐานข้อมูล หรือระบบจัดส่งจริง
- ชื่อสินค้า ราคา และรูปภาพเป็นข้อมูลตัวอย่าง สามารถแก้ไขได้ใน store.js
- หากต้องการใช้งานจริง ควรเพิ่ม Backend, ระบบสมาชิก, ฐานข้อมูล, การจัดการสต็อก และระบบชำระเงินที่ปลอดภัย
